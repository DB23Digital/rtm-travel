Front-End Website Design Brief

Client: RTM Travel
Website: rtmtravel.co.za
Business type: Corporate Travel Management (B2B)
Goal: Ultra-modern, premium, high-trust website that converts corporate decision-makers into qualified leads.

1) Project Objectives

Primary objective: Generate corporate travel enquiries (and demo/consultation requests) from:

CFOs / Finance Managers

Travel Managers / Procurement

Executive Assistants (EA) supporting leadership teams

SME founders/ops leads who travel frequently

Secondary objectives:

Establish RTM as “premium + reliable + tech-enabled”

Communicate clear service scope (travel, accommodation, groups, meetings, events—if applicable)

Reduce friction for enquiry (fast forms, WhatsApp/call, calendar booking optional)

Success metrics (trackable):

Form submissions (lead volume + quality)

Click-to-call / WhatsApp clicks

Time on page + scroll depth on key landing pages

Conversion rate per traffic source

2) Brand & Visual Direction

Design personality: Corporate confidence, minimal luxury, crisp and futuristic—but still warm and human.
Look & feel keywords: “Executive”, “calm”, “precision”, “high-end”, “efficient”, “global”.

Modern design trends to apply:

Glassmorphism: Frosted panels, subtle blur, layered depth, soft highlights

Bento grids: Modular content tiles for services, proof, stats, quick actions

Soft gradients: restrained, not neon; used for emphasis and background atmospherics

Micro-interactions: hover states, subtle parallax, smooth scroll reveals

Editorial typography: strong hierarchy, spacious layouts, confident headlines

Avoid:

Generic stock-heavy “travel agency” vibe

Busy carousels, cluttered hero sliders

Loud colors, gimmicky animations, excessive blur harming readability

3) Target Audience & Messaging Priorities

They want certainty, control, responsiveness, and cost visibility.

Primary promises the design must reinforce:

“You’ll never be stuck—support is fast.”

“Your travel spend is visible and managed.”

“We handle complexity: changes, cancellations, approvals, policy.”

“We keep travellers safe and on time.”

Home Page (structure)

Subheading: RTM value prop in one breath

Primary CTA: “Request a corporate travel consult”

Secondary CTA: “Get a quote”

Trust signals: client logos, years in business, response time (only if true), rating/testimonial snippet

Bento grid section: “What we handle”
Tiles for:

Flights

Accommodation

Policy + approvals

VIP / executive (if applicable)

Groups & events (if applicable)

Proof + outcomes

Case study cards

How it works (3 steps)

Visual timeline / steps component

CTA band

6) UI Components to Build (Reusable System)

Glass “card” component (2 blur strengths for light/dark backgrounds)

Bento grid layout system (responsive 1–4 columns)

Sticky header with compact CTA

Service feature tiles with icon + 2 lines of copy

Testimonial cards

Case study cards with outcome highlights

FAQ accordion (policy, invoicing, after-hours, changes)

Contact form with validation + success state

Optional: “Travel Request” mini-form module embedded site-wide

7) Design System Guidelines

Typography

Use 1–2 modern sans-serif families (e.g., Inter / Satoshi / Manrope style) with strong hierarchy:

H1: bold, large, tight line-height

H2: clean, spaced

Body: highly readable, generous spacing

Spacing & layout

8pt spacing system

Big padding on cards (avoid cramped glass panels)

Max content width ~1200–1280px

Mobile-first responsiveness: design for 360px widths upwards

Color approach

Neutral base (dark slate / charcoal + off-white)

Accent color used sparingly (buttons, highlights, links)

Background gradients subtle and slow (not noisy)

Accessibility

Contrast checks (glass panels can destroy readability)

Reduce motion option

Keyboard-friendly nav + form focus states

8) Motion & Interaction

Subtle scroll reveal (fade + translate)

Hover elevation for bento tiles

Button micro-interactions (press states, soft glow)

Optional: low-key parallax in hero background (very restrained)

Performance rule: animations must not tank Core Web Vitals.

9) Content & Copy Guidance (for the designer to accommodate)

Design must support short, punchy “corporate outcomes” copy:

“Fewer travel disruptions.”

“Faster changes.”

“Clear approval flows.”

“Spend visibility and reporting.”

Include sections that can easily swap copy later without breaking layout.

10) Technical Requirements (Front-End)

Framework: Next.js or modern static stack (acceptable alternatives if agreed)

Styling: Tailwind CSS recommended for speed + consistency

Components: build as reusable blocks

SEO-ready: proper H tags, metadata, OpenGraph, fast load

Analytics-ready: GA4 + conversion events for form submit, WhatsApp click, call click

Forms: spam protection (honeypot + rate limiting; reCAPTCHA optional)

Hosting: optimized images (next/image), lazy-loading where appropriate

11) Trust & Compliance UX

Corporate buyers look for legitimacy:

Clear contact info + business identifiers (if available)

Privacy policy and POPIA-aligned contact form wording (South Africa context)

Transparent “what happens after you submit” message

12) Deliverables

Designer must produce:

High-fidelity UI designs for:

Home

Service detail page

Case studies/testimonials page

Contact page

Mobile + desktop breakpoints

Component library / style guide (colors, type scale, spacing, buttons, cards)

Interaction notes (hover, scroll, sticky behaviour)

Exportable assets (SVG icons, logo variants, favicons)

Optional (recommended):

A design in Figma with auto-layout, components, and tokens

A “landing page template” that RTM can clone for campaigns

13) Creative North Star (one sentence)

RTM Travel should feel like a calm, high-control command center for corporate travel—premium, modern, and unshakeably reliable.
