## 3. Internal Link Matrix

To preserve link equity and ensure AI crawler discoverability, the cluster must use a **strict bidirectional linking structure**:

| Link Source URL | Link Target URL | Link Type | Anchor Text Context |
|---|---|---|---|
| **Any Spoke Page** | **Its Cluster Pillar** | Spoke to Pillar | *"using a structured [corporate travel policy template]..."* |
| **Cluster Pillar** | **All Spoke Pages** | Pillar to Spoke | *"our detailed guide on [TMC pricing structures]..."* |
| Homepage | All Cluster Pillars | Root to Pillar | Link blocks in footer and services overview. |
| Spoke 1 (TMC Fees) | Spoke 2 (Hotel Rates) | Spoke to Spoke | *"while negotiating hotel rates, understand [TMC fee differences]..."* |
| Spoke 2 (Hotel Rates) | Spoke 1 (TMC Fees) | Spoke to Spoke | *"leveraging volume discounts alongside [transparent transaction fees]..."* |
